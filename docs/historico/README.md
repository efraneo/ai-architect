# Documentos históricos

Estos diecisiete documentos describen la arquitectura de AI Architect **antes de
septiembre de 2026**: motor de decisiones, enjambre de agentes, consenso, modo
autónomo. Parte de ese código sigue en el repositorio (`decision_engine/`,
`planner/`, `execution/`, `agents/`) y parte se podó por huérfano. Se conservan
como referencia de dónde viene el proyecto; no describen cómo funciona hoy.

Lo actual está en [`../ARCHITECT.md`](../ARCHITECT.md) y en el `README.md` de la raíz.
